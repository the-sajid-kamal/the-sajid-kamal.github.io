# Photos

Drop photos into this folder with these names and they appear on the site automatically.
No code changes needed. JPG, PNG, WebP or AVIF; Astro resizes and compresses them.

| File | Where it appears | Best size |
| --- | --- | --- |
| `portrait.jpg` | Home page, arched portrait | 1200 × 1500 (4:5) or larger |
| `about.jpg` | About page portrait | 1200 × 1500 (4:5) |
| `headshot.jpg` | Small round photo on articles | 400 × 400 (square) |
| `work/<project>.jpg` | Project cover, e.g. `work/sui-chokri.jpg` | 2000 × 1250 |
| `work/<project>-1.jpg`, `-2.jpg` | Project gallery photos | 1500 × 1000 (3:2) |
| `writing/<article>.jpg` | Article cover, e.g. `writing/why-the-shelf-still-beats-the-screen.jpg` | 2000 × 1000 |

`legacy-sajid-kamal.jpg` is the photo from the old site. To use it as the portrait for now,
copy it to `portrait.jpg`. It is small (640 × 640), so a new photo will look much sharper.
